  Use when running /kaotim-init to copy the CLI into .kaotim/bin, create a

Run `python scripts/kaotim.py init` from the plugin or copied CLI. Ensures `.kaotim/bin/kaotim.py`, stack draft, `project-profile.md`, and gitignore entries. Review generated files with the user.
