---
name: arch-comparison
description: Use when a plan requires comparing architecture options (new service, storage, framework, or integration choice) to present tradeoffs and record Chosen/Rejected
---

Offer 2–3 options plus Other, using the `kaotim-planning` lettered question table. For each option: complexity, deps, operability, fit to profile. Mark simplest viable. User chooses by letter; record Chosen/Rejected under plan section **S — Scope & Constraints**. No silent default.
